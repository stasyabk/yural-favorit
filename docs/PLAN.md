# YURAL FAVORIT — план разработки

**Версия:** 1.0  
**Статус:** этап 1 завершён и принят пользователем

## Рабочий процесс

Каждый этап выполняется **только после отдельного разрешения пользователя**. Перед работой прочитать `AGENTS.md`, `docs/PROJECT.md`, `docs/ARCHITECTURE.md` и текущий этап этого файла. После этапа запустить доступные проверки, показать результат и остановиться. Отмечать завершение задач только после фактической проверки и принятия пользователем.

- [ ] Положить `AGENTS.md` и документы в репозиторий.
- [ ] Проверить согласованность документов с RTK Query / `fetchBaseQuery`.
- [ ] Инициализировать Git **внутри `yural-favorit`**, если он ещё не создан.
- [ ] Проверить `.gitignore` для будущих локальных секретов.
