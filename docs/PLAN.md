## Формат отчёта Codex

После каждого этапа сообщить:

1. **Выполнено** — перечень выполненных задач.
2. **Изменённые файлы** — список файлов.
3. **Проверки** — команды и реальные результаты.
4. **Проблемы** — ограничения и незавершённые вопросы.
5. **Следующий этап** — только рекомендация, **не начинать автоматически**.

После отчёта остановиться до явного подтверждения пользователя. Не менять статусы «Завершён» до проверки и принятия.
